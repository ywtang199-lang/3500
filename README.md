# 法语核心3500｜15天打卡

面向法语学习的核心词汇计划，目标为 3500 条，在 15 天内完成每日打卡。词条包含法语词头、IPA、词性、简明中文义项，以及必要时的介词搭配。

## 当前进度

已整理 **468 / 3500 条（13.4%）**，Day 1 和 Day 2 各 234 条。当前仓库保存的是这两天的已整理内容，后续词条尚未完成。

## 文件

- `核心词库_母数据.json`：词条母数据与精简来源核对信息。
- `法语核心3500_15天打卡.xlsx`：打卡工作簿。
- `中法学习版_*.md`、`法填中练习版_*.md`、`中填法练习版_*.md`：三种同序学习与练习版。
- `法语核心3500_Day*_打印版.pdf`：打印版。
- `15天打卡_进度概览.html`：打卡进度概览。
- `生成交付文件.py`：从母数据生成交付文件。
- `继续制作说明.md`：选词、释义和续编规则。
- `方法与来源.md`、`首批质检报告.json`：来源、许可说明和质检记录。
